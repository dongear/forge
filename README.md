# Forge

Межвузовское пространство, где студенты находят партнёров, собирают команды и вместе доводят проекты до результата.

## Страницы

- `index.html` — заглушка сайта
- `splash.html` — экран-заставка при запуске
- `about.html` — страница «О проекте»
- `profile.html` — личный кабинет (пример внутренней страницы)

Сайт статический: достаточно открыть `index.html` в браузере.

## Технологии

HTML и CSS без фреймворков, шрифт Inter (Google Fonts), графика на встроенном SVG.

## Использование ИИ

Код страниц написан с помощью ИИ-ассистента Claude (Anthropic) в чате Claude. Работа велась так:

- команда подготовила описание проекта и визуальный стиль в Figma (прототип «forge»);
- по этому описанию и стилю Claude сгенерировал HTML и CSS страниц;
- команда проверила результат, внесла правки и загрузила файлы в этот репозиторий.

Тексты, названия и идея проекта принадлежат команде. Данные в личном кабинете (`profile.html`) вымышленные и служат примером.
